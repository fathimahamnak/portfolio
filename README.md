# 🎮 Fathima Hamna K - GTA V Style 3D Interactive Portfolio

An immersive, playable 3D open-world developer portfolio inspired by GTA V and modern cyber aesthetics. Walk, drive sports cars, explore tech headquarters, and discover my projects, skills, and experience in an interactive virtual world built with **Three.js** and **Vanilla Web Technologies**.

---

## 🌟 Highlights & Features

- **🌆 3D Open-World City**: Built with Three.js featuring dynamic lighting, realistic textures, realistic buildings, and foliage.
- **🚗 Drivable Supercars & Character Controls**: Smooth third-person character movement, vehicle physics, camera tracking, and sound effects.
- **🏢 Interactive Project Headquarters**: Explore physical buildings representing real-world projects with interactive detail popups.
- **💻 Interactive Retro Terminal**: Built-in developer command-line terminal to inspect developer background, skills, and commands.
- **🎵 Dynamic Audio Engine**: GTA-style loading sequence, background ambient soundscapes, engine audio, and interaction SFX.
- **📱 Fully Responsive**: Custom HUD and layout that adapts gracefully across devices.

---

## 🛠️ Tech Stack

- **Graphics & 3D**: [Three.js](https://threejs.org/), GLTF / DRACO 3D model loaders
- **Frontend**: HTML5, Vanilla CSS3 (Custom Glassmorphism & Cyberpunk/GTA aesthetics), Modern JavaScript (ES6+)
- **Server**: Node.js HTTP server for local serving and correct MIME-type handling (supporting `.glb`, `.wasm`, `.mp3`)
- **Assets**: Optimized GLTF/GLB 3D models and textures

## 🚀 Getting Started

### Prerequisites
- Modern web browser with WebGL enabled (Chrome, Edge, Firefox, Brave, Safari)
- Optional: [Node.js](https://nodejs.org/) installed to run the local server

### Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/fathimahamnak/portfolio.git
   cd portfolio
   ```

2. **Start the local server:**
   ```bash
   node server.js
   ```

3. **Open in your browser:**
   Navigate to `http://localhost:3000`

*(Alternatively, you can open `index.html` directly or with VS Code Live Server)*

## 🎮 Controls

| Key | Action |
| --- | --- |
| `W / A / S / D` or Arrow Keys | Move Character / Steer Vehicle |
| `Shift` | Sprint / Boost Speed |
| `Space` | Jump / Handbrake |
| `E` | Enter / Exit Vehicle or Interact with Buildings |
| `C` | Change Camera Perspective |
| `T` | Toggle Developer Terminal |
| `M` | Mute / Unmute Audio |
